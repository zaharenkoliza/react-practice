# React Practice

Учебный проект по React, который мы развиваем на практических занятиях в течение семестра.
На одном приложении разбираем новые темы и постепенно улучшаем код.

На прошлой паре сделали список пользователей с карточками, поиском по имени,
фильтром «только онлайн» и переключением статуса. Разобрали компоненты, props,
`useState`, обработку событий и работу с массивами.

Дальше будем разделять код по ответственности, выделять компоненты,
подключать CSS Modules и добавлять новые возможности по мере изучения React.

## Запуск

Нужен Node.js 22.22.2 (версия указана в `.nvmrc`).

```bash
npm ci
npm run dev
```

Откройте адрес, который появится в терминале.

## Работа на паре

Сделайте **Fork** репозитория и склонируйте свою копию:

```bash
git clone https://github.com/YOUR_LOGIN/react-practice.git
cd react-practice
git switch -c practice
```

Замените `YOUR_LOGIN` на свой логин GitHub. Запустите проект и пишите код вместе с преподавателем.
В конце пары сохраните то, что успели сделать:

```bash
git add src
git commit -m "Работа на практике"
git push -u origin practice
```

Если меняли файлы вне `src`, добавьте их в коммит отдельно.
Откройте **Pull request** из своей ветки в `main` репозитория `zaharenkoliza/react-practice`.
В названии укажите имя и группу; описание заполнять не нужно.
PR нужен, чтобы преподаватель видел, кто что делал на паре. Можно отправлять и незавершённую работу.
Следующие коммиты в эту ветку автоматически появятся в том же PR.
